Changelog

Everything shipped, big and small.

The main series covers the big features. This page is everything else — fixes, polish, and smaller additions that don't need their own Part.

What's coming next

Being explored right now — no promises on order or timing.

Faster dead air removal

Cut Dead Air is on hold — it worked well on shorter clips, but was too slow on long footage with only a few small gaps. Looking for a faster approach that doesn't compromise reliability.

Bring your own music

Lay your own audio file under a clip, with automatic ducking so it doesn't drown out speech.

Smart vertical reframing

A crop that actually follows the subject, instead of a fixed center crop.

Scenario-description AI assembly

Describe the edit you want in plain language, and have it built for you.

VidBash timeline

A visual, draggable timeline for VidBash instead of the current list-based sequence.

Better scoring signals

Scene-change detection and blur/focus filtering, to make Highlight Reel's picks even more reliable.

Removed

Cut Dead Air (on hold)

Pulled from the app for now — not because it's broken, but because it wasn't fast enough to be worth charging for on one real, common case: a long file with only a few small gaps to cut. A speed fix was attempted (skipping re-encoding in favor of a much faster stream copy), but it introduced its own real bug — corrupted timestamps in the exported file that went on to break thumbnail generation — so it was reverted in favor of reliability over speed. Still finds and cuts dead air correctly on shorter clips; the plan is to bring it back once there's a faster approach that doesn't trade away correctness to get there.

Feature

Random Sampler gets its own format controls

Aspect ratio, color filter, and 4K — the same self-contained export pipeline VidBash and Highlight Reel already use, now on Random Sampler too.

Feature

Fade out

Fades video and audio together over the last 1.5 seconds instead of stopping abruptly. Available on every export path — the main editor, VidBash, Highlight Reel, and Random Sampler.

Feature

4K detection

The "4K" upscale option now disables itself automatically when a clip is already 4K — upscaling something that's already there doesn't add anything, and re-running it through a scaling step for no reason can introduce subtle softening. Checked against the actual source resolution the moment a clip loads, everywhere 4K shows up in the app.

Fix

A stale reference crashed every clip import

A leftover call to state removed during the Cut Dead Air cleanup was silently throwing on every single import — which, among other things, was interrupting the new 4K detection check right when it needed to run.

Feature

Highlight Reel is back

Fully rebuilt from scratch — not patched, rebuilt. Validated first with a standalone command-line test harness run directly against the exact real 33-minute 4K file that broke the original, confirming the core scoring and selection logic was sound before any of it went back into the app. Now lives in its own self-contained modal (same isolation pattern as VidBash) with its own aspect ratio, 4K, and color controls, separate from the main editor's shared export settings — the leading theory for what caused the original failures.

Feature

Highlight Reel: choose what it favors

A "Favor" setting — Balanced, More motion, or More audio energy — changes which moments actually get ranked highest, not just how many get picked. Costs nothing extra to compute, since it just recombines the same already-scanned data differently.

Fix

Highlight Reel: cut the redundant re-scan

Building a reel used to silently re-run the entire expensive motion/audio/sharpness scan a second time, after already running it once for the preview. Build now reuses exactly what Scan already found.

Feature

Highlight Reel: forced reset after every build

A confirmation dialog appears once a reel finishes exporting — acknowledging it clears the loaded clip and every setting back to default, so nothing can silently carry over into the next build.

Fix

4K sources no longer get downgraded automatically

Segment extraction used a flat bitrate regardless of source resolution, meaning genuinely 4K footage was quietly encoded at a bitrate meant for 1080p. Now detects the actual source resolution and bumps the bitrate accordingly — no need to touch the 4K checkbox if the source is already 4K. Benefits Cut Dead Air too, since they share the same underlying export step.

Fix

Toolbar no longer breaks on smaller windows

Button and toggle text was wrapping mid-word ("Snap to" / "beat") as the window got narrower. Text now stays on one line, spacing shrinks progressively as the window narrows, and at the very smallest sizes a visible scrollbar appears instead of content just silently running off the edge.

Removed

Highlight Reel (temporarily)

Pulled from the app entirely — not just hidden — after it repeatedly failed on real long-form 4K footage: exporting the full source file instead of the requested clip, on top of scan times exceeding 15 minutes. Two real fix attempts (temporal spread, then a single-pass performance rewrite) didn't resolve the core issue, and continuing to sell a Pro feature that could hand back the wrong output entirely wasn't worth the risk to trust. It's back now — see above.

Site

Added the Free vs Pro page

A clear breakdown of what's free, what's Pro, and the reasoning behind where that line sits.

Feature

Color filters

Four presets — Vibrant, B&W, Warm, and Cool — tested directly against real footage before shipping. Available in both the main editor and VidBash.

Site

Clarified the free vs Pro boundary

Settled the actual rule: if the AI is making the editing decision (dead air removal, highlight scoring, templates), that's Pro. If you're doing it yourself — trim, text, VidBash, filters, export options — it's free, always. Moved Templates under Pro Features and 4K export back to free to match.

Feature

VidBash: text overlays

Add text across the whole mix, with position presets and precise timing — reusing the same export pipeline that already handled text in the main editor.

Fix

Fixed overlapping text overlays getting stuck

When two text overlays overlapped — either on the timeline or directly on the video preview — selecting one didn't actually let you drag it, since it never got brought to the front. Fixed on both the timeline and the canvas.

Fix

VidBash modal redesigned as collapsible tabs

Media pool, sequence, and text overlays are now separate collapsible sections instead of one long scrolling page — stays manageable no matter how much is in the mix.

Site

Added the Series and Updates pages

Split the growing video collection into its own page so the homepage stays short as more Parts get posted. This page is the other half of that same cleanup.

Fix

VidBash: fixed an audio glitch between mismatched source clips

Mixing clips from two different source files could produce a glitch right at the transition when their audio formats didn't match. Rebuilt the join step to normalize audio before combining, and added a live preview player so trimming a piece is no longer done blind.

Feature

VidBash — mix clips from multiple videos

Import more than one source video, pull pieces from each into a single sequence, and export the mix — including different resolutions and frame rates from different sources, normalized automatically.

Feature

Real 4K upscale export

What used to be a locked placeholder is now genuine orientation-aware 4K upscaling — vertical, square, or landscape.

Feature

Project save and load

Trims, cuts, and text overlays now persist — close the app and pick up exactly where you left off instead of starting over.

Feature

Score transparency for Highlight Reel

Every clip Highlight Reel picks now shows why — a plain-language reason plus a motion/audio breakdown, instead of an unexplained pick.

Feature

Trim, Split & Cut redesign

Rebuilt trim to be QuickTime-style and draggable, added a dedicated Split & Cut mode with click-to-position and full undo, plus precise timecode entry for frame-accurate work. Fixed several real bugs along the way: the timeline going thin when text was added, cuts becoming invisible after exiting edit mode, and a handful of broken filmstrip thumbnails.

Feature

Text and captions

Add your own text directly on the video — fonts, bold/italic, color, drag-to-position — including non-Latin scripts like Korean.

Feature

Templates and Random Sampler

One-click editing styles (fast-paced, chill, or just cleaned up), plus a genuinely randomized sampler that pulls a different set of clips every time it runs.

Feature

Highlight Reel

Automatic detection of the most interesting moments in raw footage, using motion and audio energy.

Feature

Cut dead air

The first real feature — automatic detection and removal of silence and dead pauses.
